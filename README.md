# SWYNEX-Final-Project
# Mall Customer Segmentation Analysis

## Project Overview

This project focuses on analyzing mall customer data to identify customer groups based on their annual income and spending behavior. The analysis helps businesses understand customer patterns and improve marketing strategies.

## Problem Statement

Businesses often struggle to understand different types of customers and their purchasing behavior. This project aims to segment customers into meaningful groups using customer demographics and spending patterns, enabling better decision-making and targeted marketing.

## Dataset

The dataset contains the following columns:

* Customer ID
* Gender
* Age
* Annual Income (k$)
* Spending Score (1–100)

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Power BI
* Jupyter Notebook / Google Colab

## Steps Performed

### 1. Data Cleaning

* Checked for missing values
* Removed duplicate records
* Verified data types
* Prepared clean data for analysis

### 2. Exploratory Data Analysis (EDA)

* Analyzed customer age distribution
* Studied income patterns
* Examined spending score trends
* Identified customer behavior insights

### 3. Customer Segmentation

Customers were grouped based on:

* Annual Income
* Spending Score

Segments identified:

* High Income – High Spending
* High Income – Low Spending
* Low Income – High Spending
* Low Income – Low Spending

### 4. Power BI Dashboard

Created an interactive dashboard including:

* Total Customers
* Average Income
* Average Spending Score
* Customer Distribution by Gender
* Income vs Spending Analysis
* Customer Segments

## Key Insights

* Some customers have high income and high spending behavior.
* Certain customers have high income but lower spending.
* Spending patterns vary across age groups.
* Customer segmentation helps businesses create targeted marketing strategies.

## Conclusion

This project demonstrates how data analysis and visualization can help businesses understand customers better. The insights generated can support improved customer engagement and business growth.
